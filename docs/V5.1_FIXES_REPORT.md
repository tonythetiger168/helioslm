## 二、MAJOR findings 處置(27/27,25 FIXED / 2 DEFERRED-with-disclosure)

**模型核心:** M1 O(L) 重算消除(cache 存展開 K/V;weight absorption DEFERRED,docstring 如實標注真實節省 −33% vs MHA)・M2 dead compute 刪除・M3 RoPE 惰性預算(8192 起按需擴展)・M4 head_dim 解耦 + 整除校驗・M5 pre_attn_norm 補齊、MoE 恰好一次 norm・M6 bias 僅用於選擇 + aux-free update_bias・M7 分散式路徑修復(gloo 實測)・M8 argsort 分段 dispatch(消滅 2048 次循環)・M9 batch-safe generate・M10 移除假 block_manager・M11 attention_mask 支援。

**訓練:** M12 ratio=exp(new−old)・M13 k3 KL(逐點非負)・M14 DualPipe 實現 warmup/steady(1F1B)/cooldown 交錯並如實標注單進程模擬・M15 真 FP8 量化(原生 float8 cast + STE;**並修復原生 cast 導致梯度 underflow 為 0 的隱藏 bug**)・M16 weight_scale 動態更新 + E5M2 梯度 hook・M17 AdamW + grad clip・M18 ref_model 真調用 + 凍結。

**推理:** M19/M20 寫入約定修正 + 自動塊分配・M21 真 CoW(refcount + 寫時複製)・M22 MTP causal mask・M23 hidden 鏈接 + module_index 深度・M24 共享 embed/lm_head・M25 引擎真走 paged 賬簿 + 增量 decode・M26 Request 類 + add_request・M27 HPA 單位修正(ratio 比較)。

**多模態/量化/測試:** M28 conv state 語義修正・M29 chunk 幀數修正(500ms→50 幀)・M30 跨 chunk memory + causal transformer(串流 ≡ 一次性,diff 1.9e-06)・M31 NaViT row/col 雙嵌入表・M32 奇數 in_features 修復・M33 forward_packed device/dtype・M34 測試失敗即 exit 1・M35/M36 量化與 NaViT 數值斷言補齊。

**DEFERRED(已在文檔如實披露):** MLA weight absorption(需重構注意力核);完整 GPTQ Hessian 誤差補償(當前為 RTN + GPTQ 兼容佈局)。

## 四、文檔誠實化(README)

所有無支撐數字(93.3% KV reduction、85–90% acceptance、+40%、−50% cost、95% GPU util、對標 o1、<200ms)已刪除或改為有代碼/測試支撐的功能描述;「vLLM integration」改為「vLLM-style engine」;DualPipe/GRPO/GPTQ/NaViT 的簡化取捨全部如實標注。CHANGELOG.md 新增 v5.1 完整條目。

## 五、遺留限制(如實)

- MTP 僅 batch=1;未訓練模型 acceptance=0 屬預期(機制正確性已由 greedy 等價性證明)。
- DualPipe 為單進程調度模擬,無真多卡 p2p。
- MTP 拒絕回滾採重算前綴策略(可靠優先,高拒絕率時有 O(L) 開銷)。
- 量化 dequant 為非融合實現,正確性優先;生產性能需對接 auto-gptq/exllama。
- 引擎解碼為 per-request 串行 forward,未做批量 kernel 合併。
- 量化後 MTP 與主模型的 lm_head 共享引用會弱化(named_modules 去重),功能不受影響。
