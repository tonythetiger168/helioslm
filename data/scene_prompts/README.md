# Scene prompts: short sentence -> detailed world description

`scene_prompts.jsonl`: 9 pairs. `input` is one of the eight pano2world showcase sentences
(`prompts/showcase.txt` in tonythetiger168/pano2world); `output` is the scene description World Labs
Marble (model `marble-1.1`) wrote for the world it generated from that sentence (its world caption),
as copied by the owner from Marble on 2026-11-08. `split`: `main` is one pair per sentence; `variant`
is a second Marble world from the library sentence, so the same input with a different output.
`world_id_prefix` is the first 8 hex digits of the Marble world id (platform.worldlabs.ai Generations).
MANIFEST.json holds the record count and sha256.

Use: few-shot examples or an evaluation set for teaching a model to expand a one-line place
description into a world description (layout, materials, light, where things sit relative to each
other). Nine pairs are far too few to fine-tune on.
